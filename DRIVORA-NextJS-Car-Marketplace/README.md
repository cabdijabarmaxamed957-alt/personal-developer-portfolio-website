# DRIVORA — Car Marketplace

A large Next.js App Router starter for a modern vehicle marketplace.

## Included
- Home / hero / featured vehicles
- Inventory search and filters
- Vehicle detail pages
- Favorites using localStorage
- Sell-a-car form
- Finance calculator
- Seller dashboard
- Responsive mobile navigation
- Dark futuristic visual design inspired by the supplied blue pill/button reference
- No database required for the demo

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Production expansion
Connect the existing UI to a backend/database for:
- authentication and roles
- real vehicle listings
- image storage
- sellers/dealers
- payments and deposits
- financing applications
- messages/chat
- inspection reports
- admin panel
- notifications
- analytics
